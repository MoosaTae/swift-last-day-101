**Details**

**1. Written Exam**
Closed Book | Exam duration: 45 minutes | Total score: 10 points

- **Output Prediction**
  - Short Swift code snippets will be provided. Students must analyze the code and write down what the final printed output will be.
- **Code Improvement**
  - Improve the given code and provide reasons why the code needs to be improved.
  - For example, if the code uses Force Unwrapping when converting from a String to an Int, you must specify what is wrong with this code block and state that you should use Optional Binding (`if let` or `??`) to make it safer.
- **View Decomposition**
  - A screen wireframe will be provided, and you have to write the UI using various stacks to match the wireframe as closely as possible.
  - Only basic UI components will be used, such as `VStack`, `HStack`, `Text`, `Image`.

**2. Practical Exam**
Open Book | Exam duration: 120 minutes | Total score: 20 points

- Starter code will be provided. You will be asked to add features or refactor based on the original code.
- Each student must demonstrate their understanding in reading code, debugging, and displaying data correctly to make the app function properly.
- Grading will be based on both the completeness of the app and the correctness of the logic, which will be evaluated by running Unit Tests.

**Topics Covered**
The content will follow the slides taught in class, as well as applied knowledge from self-study and various assignments. The topics you should review are as follows:

1. Swift Language Basics and Data Structures
2. Screen Layout with SwiftUI and Various Modifiers
3. State Management and User Interaction
4. Displaying Lists and Navigation (Opening New Screens)
5. API Calls and Local Data Storage (AppStorage)
